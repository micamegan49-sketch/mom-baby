# ตัวจิ๋ว 👣 — แอพดูแลแม่และลูกน้อย

เว็บแอพ (PWA) ใช้งานออฟไลน์ได้ โทนน้ำตาล–ชมพู ดูแลตั้งแต่ในครรภ์จนถึงวัยเตาะแตะ (0–5 ปี)
ข้อมูลทั้งหมดเก็บในเครื่อง (localStorage) ไม่ส่งออกไปไหน

## ฟีเจอร์
- 🤰 **โหมดตั้งครรภ์** — ติดตามรายสัปดาห์ (เทียบขนาดลูกกับผลไม้), คำนวณน้ำหนัก/BMI, นับลูกดิ้น, จับเวลามดลูกหดตัว
- 📝 **บันทึกประจำวัน** — นม / นอน / ผ้าอ้อม / สุขภาพ / โน้ต พร้อมสรุปรายวัน
- 💉 **ตารางวัคซีน** — อิง EPI ไทย คำนวณวันครบกำหนดจากวันเกิด เตือนรายการที่เลยกำหนด
- 📈 **กราฟการเจริญเติบโต** — น้ำหนัก/ส่วนสูง/รอบศีรษะ เทียบเกณฑ์อ้างอิง WHO
- 🌱 **พัฒนาการตามวัย** — เช็กลิสต์ milestone + ธงแดงที่ควรพบแพทย์
- 📚 **ความรู้** — บทความ (รวมประกัน & การเงินสำหรับเด็กแต่ละช่วงวัย) และคำถามที่พบบ่อย
- 👶 รองรับลูกหลายคน + สำรอง/นำเข้าข้อมูลเป็นไฟล์
- ☁️ **ซิงค์ข้ามเครื่อง (ทางเลือก)** — ล็อกอินด้วยอีเมล สำรอง/ซิงค์ข้อมูลขึ้นคลาวด์ผ่าน Supabase (มือถือ↔คอม) ยังใช้ออฟไลน์ได้เหมือนเดิม

## วิธีเปิด
ดับเบิลคลิก `start.command` หรือสั่งในเทอร์มินัล:
```
cd ~/mom-baby && python3 -m http.server 8848
```
แล้วเปิด http://localhost:8848 (บนมือถือใช้ http://<IP เครื่อง>:8848 บน Wi-Fi เดียวกัน)

## ☁️ ตั้งค่าซิงค์ข้ามเครื่อง (Supabase) — ทางเลือก
ถ้าจะใช้แค่ในเครื่องเดียว **ข้ามขั้นตอนนี้ได้เลย** แอพทำงานออฟไลน์ครบทุกฟีเจอร์อยู่แล้ว
อยากซิงค์ข้อมูลระหว่างมือถือกับคอม ทำครั้งเดียว:

1. สมัคร/ล็อกอินที่ [supabase.com](https://supabase.com) → **New project** (แพลนฟรีพอ) ตั้งรหัสฐานข้อมูลแล้วรอสร้างเสร็จ
2. เปิด **SQL Editor** → วางเนื้อหาไฟล์ [`supabase/schema.sql`](supabase/schema.sql) ทั้งหมด → **Run** (สร้างตาราง + Row Level Security + เปิด Realtime)
3. ไปที่ **Project Settings → API** คัดลอก **Project URL** กับ **anon public key**
4. ในแอพ: **ตั้งค่า → ☁️ บัญชี & ซิงค์** → วาง URL + คีย์ → บันทึก → สมัคร/เข้าสู่ระบบด้วยอีเมล
5. ทำขั้นตอนเดียวกัน (ขั้น 4) บนเครื่องอื่นด้วยคีย์ชุดเดิม แล้วล็อกอินบัญชีเดียวกัน — ข้อมูลจะซิงค์ให้อัตโนมัติ

> 🔐 ใส่ **anon/public key** เท่านั้น (ปลอดภัยสำหรับฝั่งหน้าเว็บ เพราะ RLS บังคับให้แต่ละบัญชีเห็นเฉพาะข้อมูลตัวเอง) — **อย่าใส่ service_role key**
> คีย์ที่กรอกในแอพเก็บไว้ในเครื่องนั้น ๆ (localStorage) ไม่ได้ commit ลงโค้ด

## โครงสร้าง
```
index.html             หน้าหลัก + โหลดสคริปต์
manifest.json, sw.js   ตั้งค่า PWA + ออฟไลน์
css/styles.css         ดีไซน์ (โทนน้ำตาล–ชมพู)
js/store.js            ชั้นเก็บข้อมูล (localStorage) + hook ซิงค์
js/app.js              เราเตอร์ + ตัวช่วย + แถบนำทาง + ชีต
js/cloud.js            คลาวด์ซิงค์ผ่าน Supabase (auth + push/pull + realtime)
js/data/*.js           ข้อมูล: วัคซีน, เกณฑ์ WHO, พัฒนาการ, บทความ, ตั้งครรภ์, ราคา รพ., คีย์ Supabase
js/views/*.js          หน้าจอแต่ละหน้า
supabase/schema.sql    สคีมาฐานข้อมูล + RLS (วางใน Supabase SQL Editor)
icons/                 ไอคอนแอพ
```

## ⚠️ ข้อควรทราบ
ข้อมูลวัคซีน เกณฑ์การเจริญเติบโต พัฒนาการ และบทความ เป็น **ข้อมูลอ้างอิงทั่วไปเพื่อความรู้**
ไม่ใช่คำวินิจฉัยทางการแพทย์/คำแนะนำการเงินเฉพาะบุคคล โปรดยึดสมุดสุขภาพเด็กและคำแนะนำของแพทย์เป็นหลักเสมอ

## ต่อยอดได้ในอนาคต
- คอมมูนิตี้ถาม-ตอบจริง (ต้องมีเซิร์ฟเวอร์/ฐานข้อมูล)
- แจ้งเตือนวัคซีน/นัดหมาย (push notification)
- นำขึ้นโฮสต์ HTTPS เพื่อ “เพิ่มลงหน้าจอโฮม” บน iPhone และใช้ออฟไลน์เต็มรูปแบบ
